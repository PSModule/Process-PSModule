# Process-PSModule

Process-PSModule is the core workflow of the PSModule framework. This end-to-end GitHub Actions workflow builds, tests, versions, documents, and publishes PowerShell modules to the PowerShell Gallery.

Documentation site generation is powered by Zensical. Repositories define site configuration in `zensical.toml`.

## Documentation

The full documentation is published at:

📖 **[Process-PSModule documentation](https://psmodule.io/Process-PSModule/)**

It covers getting started, the pipeline stages, usage, configuration, repository structure, and the principles behind the framework.
