# Semantic Versioning

Semantic Versioning (SemVer) uses the three-part version format `MAJOR.MINOR.PATCH`. The version number indicates whether a change affects compatibility, adds functionality, or fixes a bug.

**Example**: Version 1.2.3 where 1 is major, 2 is minor, and 3 is patch.
